# Working agreements

- Static site for GitHub Pages: HTML, CSS, plain JavaScript, relative asset URLs, hash-based navigation. No build or external runtime assets.
- Bahasa Indonesia. Product is **Belajar Anak**, a paid parent's workspace.
- **Focus: help the parent teach at home with communicative worksheets and ready-made instructions.** Progress tracking is a by-product of recorded sessions, never the headline. Do not add journals, portfolios, child-facing play modes, or planning tools the parent has to configure.
- One learning code unlocks one level (`TKB-…` / `SD1-…`), because packages are sold per age. Never offer a level switcher; the child's age only checks the code for a mismatch.
- The 30-day package is generated, not configured. Keep it interleaved across the eight domains.
- A lesson opens with benefit and expected outcome, then one single work page: materials, instructions, worksheet, questions, result. No steppers, no tabs, no page hops.
- Write informative sentences: concrete, checkable, no poetic headings and no claims of school readiness.
- Quiz answers must not cluster in one position, and must never assume a particular child's name.
- Hash routing is in use, so in-page jumps are buttons that call `scrollIntoView`, never `href="#section"`.
- Persist changes per child in localStorage, escape user text, validate imported backups, and handle unavailable/full storage visibly.
- Run `npm test`, syntax checks, and verify affected desktop/mobile flows before pushing.
- Use small commits: `<area>: <ringkasan>`. Do not enable hosting unless the user asks.
